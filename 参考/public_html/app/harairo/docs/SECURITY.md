# セキュリティ機能

## ログイン保護

### レート制限

システムは以下のレート制限を実装しています:

- **最大試行回数**: 5回
- **監視期間**: 15分
- **ロックアウト時間**: 15分

### 動作

1. **失敗記録**: パスワード失敗時にIPアドレスとユーザーIDの組み合わせで記録
2. **試行回数表示**: 残り試行回数をユーザーに表示(残り回数が1回以上の場合)
3. **アカウントロック**: 5回失敗するとアカウントが15分間ロック
4. **自動解除**: ロック時間経過後、自動的に解除
5. **成功時リセット**: ログイン成功時に試行回数をリセット

### ログ記録

以下のイベントが `data/security.log` に記録されます:

- `login_failed`: ログイン失敗 (ユーザーID、IP、タイムスタンプ)
- `login_success`: ログイン成功 (ユーザーID、IP、タイムスタンプ)

### データ保存

レート制限データは `data/rate_limits.json` に保存されます。

### IP識別

以下の順序でクライアントIPを識別します:

1. `HTTP_X_FORWARDED_FOR` (プロキシ経由の場合)
2. `HTTP_CLIENT_IP`
3. `REMOTE_ADDR`

## ブルートフォース攻撃への対策

- IPアドレスベースの制限により、同一IPから複数アカウントへの攻撃を防止
- 試行回数の記録により、分散攻撃の検出が可能
- セキュリティログにより、攻撃パターンの分析が可能

## メンテナンス

### ログファイルのローテーション

`data/security.log` は定期的にローテーションすることを推奨します。

### レート制限データのクリーンアップ

システムは自動的に期限切れのレート制限データを削除します:
- ロック解除時間を過ぎたレコード
- 1時間以上前の試行記録
