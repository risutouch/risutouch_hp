パスワードリセット手順書
======================

※ この手順はFTPアクセス権限を持つ管理者専用です

パスワードを忘れた場合のリセット方法
----------------------------------

1. FTPソフトで data/users.json をダウンロード

2. テキストエディタで開く

3. 該当ユーザーの "password_hash" の値を以下に置き換え:

   "$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi"

   例:
   {
       "id": "supplier",
       "login": "risutouch",
       "password_hash": "$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi"
   }

4. 保存してFTPでアップロード（上書き）

5. ブラウザでログイン画面にアクセス
   - ログインID: risutouch (または engawa)
   - パスワード: password

6. ログイン成功したら、すぐに設定画面で新しいパスワードに変更する

注意事項
--------
- このファイルは管理者のみが保管してください
- FTPパスワードは厳重に管理してください
- リセット後は必ず新しいパスワードに変更してください
